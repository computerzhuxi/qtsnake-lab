# Snake Arena 重设计文档

## 1. 项目最终形态

基于 Qt5 的多模式贪吃蛇对战平台，四种模式：

- **单人经典模式**：键盘操控，吃食物增长，撞墙或撞自己结束。
- **AI 对战模式**：可选择 AI 难度与数量，AI 使用 BFS 寻路 + 跟随尾巴策略。
- **联机对战模式**：支持局域网直连与公共服务器两种方式。
- **对局回放模式**：可录制并回放任意模式的对局，支持播放/暂停/倍速。

构建产物两个可执行文件：

- **SnakeArena.exe**（客户端）——玩家使用的完整程序，包含全部 UI 与游戏逻辑。
- **SnakeServer.exe**（服务端）——纯网络服务进程，部署到公网服务器，无 GUI。

## 2. 视觉设计

### 2.1 整体风格

暗色电竞 / TRON 风格：

- 棋盘底色纯黑（`#06060f`），格子间微弱分隔线，外包发光边线
- 蛇身 **方块** 造型，小圆角，各节从头部到尾部颜色渐变，霓虹发光效果
- 食物 **圆形**，带彩色光晕，不同颜色代表不同类型
- 所有文字使用等宽字体，标题大字间距宽松，信息字小而紧凑
- 主色调：霓虹绿 `#00ff88`（蛇、高亮操作）、霓虹红 `#ff6688`（食物、危险操作、结算）、青色 `#0ff`（选中/提示）

### 2.2 配色参考

| 用途 | 颜色 | 说明 |
|------|------|------|
| 背景（最深） | `#06060f` | 窗口/棋盘底色 |
| 面板背景 | `#0a0a1a` / `#08081a` | 弹窗/信息区 |
| 按钮常态 | `#0d0d28` | 按钮背景 |
| 按钮边框 | `#222255` | 默认边框 |
| 高亮边框 | `#00ff88` | 悬停/选中 |
| 文字主色 | `#ccc` | 普通文字 |
| 文字亮色 | `#e0e0ff` | 标题文字 |
| 文字暗色 | `#556` | 辅助信息 |
| 蛇身 | `#00ff88` → `#00bb55` | 头部到尾部渐变 |
| 食物 | `#ff4466` / `#ffaa00` | 不同类型 |
| 危险/退出 | `#ff6688` | 退出按钮、游戏结束标题 |

## 3. 应用外壳架构

### 3.1 页面组织方式：游戏底层 + 浮层叠加

游戏画面始终在窗口底层运行，所有界面（菜单、弹窗、设置）作为浮层覆盖在上方，通过 `show()` / `hide()` 控制显隐。

```
QWidget (顶层窗口)
  ├── QGraphicsView    ← 游戏画面，始终最底层
  ├── MainMenuWidget   ← 主菜单浮层（全屏）
  ├── PauseWidget      ← 暂停/选项浮层
  ├── GameOverWidget   ← 结算浮层
  ├── SettingsWidget   ← 设置浮层（全屏）
  └── ... 其他弹窗
```

浮层实现为自定义 QWidget，使用半透明遮罩背景，弹窗居中显示。

### 3.2 UI 渲染方式

- **游戏画面**：`QGraphicsView` + `QGraphicsScene` + `QGraphicsItem`（蛇、食物、棋盘格）
- **所有界面 UI**：QSS（Qt Style Sheets），全局样式文件 `src/resources/style/main.qss`，`main.cpp` 启动时通过 `qApp->setStyleSheet()` 全局加载，各组件通过 `objectName` 做差异化覆盖

### 3.3 资源打包

使用 Qt 资源文件 `.qrc` 将所有资源编译进可执行文件：

```
src/resources/
├── resources.qrc
├── style/main.qss
├── fonts/              # 等宽字体
├── audio/              # 音效文件（预留）
└── i18n/               # 翻译 .qm 文件
```

## 4. 界面流转

### 4.1 总览

```
[主菜单]（全屏浮层）
  ├─ 单人经典 → 主菜单消失 → 按任意键 → 3-2-1 → 游戏开始
  ├─ AI 对战  → AI 配置弹窗 → 主菜单消失 → 按任意键 → 3-2-1 → 游戏开始
  ├─ 局域网对战 → 局域网子页面
  ├─ 服务器对战 → 服务器子页面
  └─ 对局回放 → 回放列表弹窗 → 播放
```

### 4.2 局域网对战流程

```
主菜单 → 局域网对战
          ├─ 创建房间（房主）
          │     ├─ 内嵌 GameServer 自动启动
          │     ├─ 显示本机 IP + 端口
          │     └─ 房间大厅
          │           ├─ 玩家列表 + 准备状态
          │           ├─ 房主可设置：棋盘大小、游戏速度、网格、食物闪烁
          │           ├─ 全部准备 → 房主开始 → 3-2-1 → 游戏开始
          │
          └─ 加入房间（其他玩家）
                ├─ 输入房主 IP + 端口 → 连接
                └─ 房间大厅（同上）
```

### 4.3 服务器对战流程

```
主菜单 → 服务器对战
          └─ 输入服务器 IP → 连接 → 房间列表
                                      ├─ 选择房间加入
                                      └─ 创建新房
                                      ↓
                                   房间大厅（同局域网）
```

### 4.4 游戏中（单机：单人/AI）

```
ESC → [暂停弹窗]
        ├─ 继续游戏
        ├─ 重新开始
        ├─ 设置 → 设置浮层
        └─ 返回主菜单

蛇死亡 → [结算弹窗]
          ├─ 最终分数 / 长度 / 击杀 / 用时
          ├─ 再来一局
          ├─ 保存回放
          └─ 返回主菜单
```

> **死亡帧策略**：碰撞帧不会再次渲染，玩家画面停留在撞墙前的合法位置。

### 4.5 游戏中（联机：局域网/服务器）

```
ESC → [选项弹窗]（不暂停游戏）
        ├─ 继续
        ├─ 游戏设置（只读）
        ├─ 离开房间

蛇死亡 → [结算弹窗]
          ├─ 排名 / 分数 / 统计
          ├─ 保存回放
          └─ 返回主菜单
```

### 4.6 倒计时流程

- **单机模式**：按任意键准备 → 屏幕中央 3 → 2 → 1 → GO → 游戏开始
- **联机模式**：全部准备 → 房主开始 → 屏幕中央 3 → 2 → 1 → GO → 游戏开始

| 界面 | 类型 | 包含内容 |
|------|------|---------|
| 主菜单 | 全屏浮层 | 标题、四模式按钮、设置、排行榜、退出 |

| 房间大厅 | 半屏浮层 | 玩家列表、准备状态、房主游戏设置、开始按钮 |

| 结算弹窗 | 居中弹窗 | 分数/统计/再来一局/保存回放/返回主菜单 |

### 5.1 设置页面内容

**操作标签：**
- 键位自定义（默认方向键，可改为 WASD 等）
- 语言切换（中文 / 英文，运行时生效）

**游戏标签：**
- 游戏速度（慢/中/快）
- 棋盘大小（小/中/大）
- 音量
- 显示网格（开关）
- 食物闪烁效果（开关）

## 6. 模块划分

```
src/
├── core/         # 纯 C++ 游戏模型，不依赖 Qt
│                 #   Snake, Board, Point, Direction, Food, 碰撞检测, 随机数种子
│
├── ui/           # QGraphicsView 游戏渲染
│                 #   SnakeItem, FoodItem, GameScene, GameView
│
├── app/          # 应用外壳 UI（本次重做核心）
│                 #   所有浮层组件、页面切换管理、多语言切换入口
│
├── controller/   # 游戏控制器
│                 #   QTimer 主循环、模式管理、输入整合、状态同步
│
├── ai/           # AI 决策
│                 #   BFS 寻路 + 跟随尾巴策略
│
├── network/      # 联机通信
│                 #   QTcpServer/QTcpSocket、二进制协议、
│                 #   内嵌/独立 GameServer、GameClient
│
├── replay/       # 录制与回放
│                 #   操作与种子录制、回放驱动控制器、
│                 #   文件头含对局类型标识
│
├── logging/      # 日志系统（新增）
│                 #   级别控制、控制台/文件输出、模块标签
│
├── audio/        # 音效接口（新增，先做壳）
│                 #   AudioManager::playEffect(type), 底层待对接 QSoundEffect
│
└── resources/    # 打包资源（新增）
                  #   QSS 样式、字体、翻译 .qm、音频文件
```

各模块编译为静态库，顶层 CMake 链接成两个目标。

## 7. 关键技术选型

| 技术点 | 选择 | 理由 |
|--------|------|------|
| GUI 框架 | Qt5 Widgets | 成熟稳定，QGraphicsView 适合游戏循环 |
| 图形架构 | QGraphicsView / Scene / Item | 内置碰撞检测、坐标变换 |
| UI 样式 | QSS（全局样式表） | 统一暗色电竞风，不依赖系统原生样式 |
| 应用外壳 | 游戏底层 + 浮层叠加 | 接近游戏体验，暂停/菜单切换自然 |
| 游戏循环 | QTimer（~100ms） | 与 Qt 事件循环融合，无需手动管理线程 |
| AI 算法 | BFS + 跟随尾巴 | 经典可靠，不依赖外部库 |
| 网络模型 | 权威服务器 C/S over TCP | 防作弊、同步简单，TCP 保证可靠传输 |
| 网络 API | QTcpServer / QTcpSocket | 信号槽异步编程 |
| 序列化 | QDataStream + 自定义二进制协议 | 轻量高效，跨平台字节序可控 |
| 随机数 | std::mt19937（支持种子注入） | 保证回放确定性 |
| 测试 | Google Test | 独立测试核心逻辑 |
| 构建 | CMake 静态库 + 两个 target | 模块依赖清晰，增量编译快 |
| 多语言 | QTranslator + Qt Linguist | 运行时切换，无需重启 |
| 资源打包 | Qt .qrc | 所有资源编译进 exe，不依赖外部文件 |
| 服务端 | 独立可执行文件 | 与客户端共用 network/core 代码，无 GUI |

## 8. 客户端-服务端关系

```
SnakeArena.exe                    SnakeServer.exe
┌──────────────┐                  ┌──────────────┐
│  app         │                  │  main_server │
│  ui          │                  │  logging     │
│  controller  │                  │  network ────┼──→ core
│  ai          │                  └──────────────┘
│  replay      │                        ↑ TCP
│  audio       │                        │
│  logging     │                  ┌──────┴───────┐
│  network ────┼──→ core          │ 客户端们      │
│  resources   │                  └──────────────┘
└──────────────┘
```

- 局域网模式：客户端进程内嵌 GameServer（复用 network 模块），无需独立 exe
- 服务器模式：SnakeServer.exe 独立部署，各客户端通过 IP 连接
- 同一套 network 模块代码、同一套二进制协议

## 9. 构建系统

顶层 CMake 定义两个 target：

| Target | 链接模块 | 说明 |
|--------|---------|------|
| SnakeArena | core + ui + app + controller + ai + network + replay + logging + audio + resources | 客户端 |
| SnakeServer | core + network + logging | 服务端 |

每个模块一个 `CMakeLists.txt`，输出静态库（如 `libcore.a`）：

```
SnakeArena/
├── CMakeLists.txt              # 顶层
├── src/
│   ├── core/CMakeLists.txt
│   ├── ui/CMakeLists.txt
│   ├── app/CMakeLists.txt
│   ├── controller/CMakeLists.txt
│   ├── ai/CMakeLists.txt
│   ├── network/CMakeLists.txt
│   ├── replay/CMakeLists.txt
│   ├── logging/CMakeLists.txt
│   ├── audio/CMakeLists.txt
│   └── resources/resources.qrc
├── tests/
│   └── CMakeLists.txt          # Google Test
├── docs/
└── plan.md
```

## 10. 多语言方案

- 代码中所有用户可见字符串使用 `tr()` 包裹
- 翻译源文件 `snake_zh.ts`、`snake_en.ts` 使用 Qt Linguist 管理
- 编译产物 `snake_zh.qm`、`snake_en.qm` 打入 `.qrc`
- 设置界面中选择语言 → `QTranslator::load()` 热切换 → `QEvent::LanguageChange` 驱动全部 UI 刷新
- 无需重启程序
