# 里程碑 5：Logger 日志系统

## 做什么

实现单例日志系统，支持控制台和文件双输出、级别过滤、时间戳，通过宏接口简化调用。

## 怎么做

- 单例 `Logger::instance()`
- 后台线程 + `std::queue` + `std::mutex` + `std::condition_variable`
- `log()` 只负责格式化字符串 + push 到队列，不阻塞调用方
- 后台线程从队列取消息，写入控制台和文件
- 析构时清空队列后再退出线程（防止日志丢失）
- `LOG_DEBUG/INFO/WARN/ERROR` 四个宏
- `setMinLevel()` / `setFile()` 同前

## 为什么这样做

- **异步非阻塞**：服务端高并发时日志不拖慢主线程
- **消息队列**：调用方不需要等待 IO 完成
- **退出时排空队列**：崩溃前的日志不丢失
- **仍保持单例 + 宏接口**：调用方写法不变
